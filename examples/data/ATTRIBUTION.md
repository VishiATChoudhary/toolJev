# Data in this folder

Built by `build.py` from public benchmark releases, for the showcase only.

- `catalog.json`: tool names, descriptions and input schemas from
  [MCPToolBench++](https://github.com/mcp-tool-bench/MCPToolBenchPP) (MIT) and
  [LiveMCPBench](https://github.com/icip-cas/LiveMCPBench) (Apache-2.0).
- `tickets.json`: 400 messages and intent labels from the
  [banking77](https://huggingface.co/datasets/PolyAI/banking77) test split
  (CC-BY-4.0; Casanueva et al., 2020).
